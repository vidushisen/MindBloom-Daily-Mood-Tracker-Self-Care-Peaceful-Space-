# 🌸 MindBloom — Daily Wellness, Mood Tracker & Peaceful Space

> A mindful, aesthetic web companion to track emotional health, practice guided breathwork, listen to procedural ambient soundscapes, and anchor through peaceful reflection.

---

## ✨ Features

- 🌸 **Daily Mood Check-in**: 5-level intuitive mood selector (*Radiant, Good, Okay, Low, Overwhelmed*) with tag factors (*Work, Sleep, Exercise, Family, Nutrition, Self-Care*).
- 📖 **Private Reflection Journal**: Local journal notes and daily 1-line gratitude prompt saved securely in your browser.
- 🫁 **Guided Breathwork Studio**: 
  - **4-7-8 Relax** (Instant Anxiety Relief)
  - **Box Breathing (4-4-4-4)** (Focus & Tactical Stability)
  - **Deep Calm (5-5)** (Heart rate coherence)
  - Interactive smooth expanding circle with real-time meditation chime audio.
- 🎧 **Browser-Synthesized Ambient Soundscapes**:
  - 🌧️ Gentle Rain
  - 🌊 Ocean Waves
  - 🔥 Cozy Fireplace
  - 🍃 Pink Noise (Sleep frequencies)
  - 🧘 Tibetan Singing Bowl (432Hz harmonic bell)
  - 🌌 Peaceful Night Crickets
  - *No external MP3 files needed — 100% procedural Web Audio synthesis that works offline!*
- 🌿 **5-4-3-2-1 Grounding Tool**: Step-by-step interactive sensory grounding guide to relieve panic and anxiety attacks.
- 📊 **Mood Analytics & Trend Chart**: Real-time 7-Day HTML5 Canvas curve chart, positive mood booster detection, and trigger breakdowns.
- 🔥 **Mindful Streak Counter**: Visual streak progression bar to encourage daily reflection habits.
- 🎨 **4 Elegant Themes**: Midnight OLED Dark, Calm Lavender, Forest Sage, and Warm Sunset.
- 💾 **Data Backup & Restore**: One-click JSON export and import to keep your private memories safe.
- 🆘 **Crisis Helplines Modal**: Quick access to national and international 24/7 mental health emergency support numbers.

---

## 🌐 Deploy Live to GitHub Pages

1. Create a new repository on GitHub named `mental-health-tracker` or `MindBloom`.
2. Push or upload all files (`index.html`, `css/`, `js/`, `README.md`).
3. Go to **Settings** → **Pages** in your GitHub repository.
4. Under **Branch**, select `main` (or `master`) and click **Save**.
5. Your live app URL will be ready in under 1 minute! 🎉
